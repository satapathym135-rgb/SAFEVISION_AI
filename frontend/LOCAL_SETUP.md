# SENTINEL AI — Run locally in VS Code

## Prerequisites

- Node.js 20 or newer (recommended: install via [nvm](https://github.com/nvm-sh/nvm#installing-and-updating))
- npm (comes with Node.js)

## Setup

```sh
npm install
npm run dev
```

The app starts on **http://localhost:3000** (Vite prints the exact port in the terminal).

## Other scripts

| Script | What it does |
| --- | --- |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |
| `npm run test` | Run the unit tests (Vitest) |

## Stack

- TanStack Start (React 19, Vite 8, file-based routing under `src/routes/`)
- Tailwind CSS v4 (design tokens in `src/styles.css`)
- shadcn/ui components (`src/components/ui/`)
- Recharts, Lucide icons

## Notes

- `src/routeTree.gen.ts` is generated by the router plugin — it is included so the
  project runs immediately, and it regenerates automatically on `npm run dev`.
- The CCTV feed uses a static image (`src/assets/cctv-floor.jpg`) with detection
  overlays drawn in code; there is no live camera dependency.
- Everything runs client-side with in-memory demo data (`src/components/sentinel/data.ts`);
  no database or API keys are required.
